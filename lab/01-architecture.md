# Практик 2 — Лабораторийн архитектур

## 1. Зорилго

Windows төхөөрөмжийн Security болон Sysmon логийг Wazuh-аар
цуглуулж, аюулгүй байдлын үйл явдлыг илрүүлэх лаборатори байгуулсан.

## 2. VM хүснэгт

| VM | Үйлдлийн систем | Үүрэг |
|---|---|---|
| wazuh-srv | Ubuntu Server | Wazuh manager, indexer, dashboard |
| WIN-EP01 | Windows Server 2022 | Wazuh agent, Sysmon |

## 3. IP төлөвлөгөө

| Төхөөрөмж | Adapter 1 | Adapter 2 — Host-only |
|---|---|---|
| wazuh-srv | NAT, DHCP | 192.168.56.10/24 |
| WIN-EP01 | NAT, DHCP | 192.168.56.20/24 |
| Хост компьютер | Интернетийн холболт | 192.168.56.1/24 |

NAT адаптерийг интернетэд холбогдох, программ татахад ашигласан.
Host-only сүлжээг VM-үүд болон хост компьютерийн хооронд холбоход ашигласан.

## 4. Логийн урсгал

1. Windows Security болон Sysmon үйл явдлыг бүртгэнэ.
2. Wazuh agent эдгээр логийг цуглуулж manager руу дамжуулна.
3. Manager логийг дүрмээр шинжилж alert үүсгэнэ.
4. Filebeat alert-ийг Wazuh indexer рүү дамжуулна.
5. Wazuh Dashboard-оос alert-уудыг хайж, дэлгэрэнгүйг харна.

## 5. Холболт

| Эх үүсвэр | Очих газар | Порт | Зориулалт |
|---|---|---|---|
| WIN-EP01 | wazuh-srv | TCP 1514 | Agent-ийн лог дамжуулах |
| Хостын браузер | wazuh-srv | HTTPS 443 | Dashboard нээх |
| Хост компьютер | wazuh-srv | TCP 22 | SSH удирдлага |
