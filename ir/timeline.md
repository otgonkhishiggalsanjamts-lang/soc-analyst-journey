## 3. Нотолгооны шинжилгээ

### 3.1. Олон удаагийн нэвтрэлтийн алдаа

Wazuh Rule 60204 нь 8 удаагийн давтамжийн босготой бөгөөд Administrator хэрэглэгчийн амжилтгүй нэвтрэлтийн үйл явдлуудыг илрүүлсэн. Windows Event ID 4625, Logon Type 2, Source IP 127.0.0.1 бүртгэгдсэн.

### 3.2. Амжилттай нэвтрэлт

Rule 60204-ийн дараа 9.536 секундын зайтай Windows Event ID 4624 бүртгэгдсэн. Хэрэглэгч, IP болон нэвтрэлтийн төрөл ижил байгаа боловч энэ нь халдагч нууц үгийг тааж нэвтэрснийг дангаараа батлахгүй.

### 3.3. Шинэ хэрэглэгч үүсгэсэн үйл явдал

10:55:17 цагт Administrator хэрэглэгч lab4triage бүртгэл үүсгэсэн. Үүний дараа тухайн хэрэглэгч Builtin Users бүлэгт нэмэгдсэн. Administrators бүлэгт нэмэгдсэн нотолгоо энэ бүртгэлд байхгүй.

## 5. Incident Response-ийн санал болгож буй арга хэмжээ

### Detection & Analysis
- Alert-уудын timestamp, хэрэглэгч, IP, Logon Type, Logon ID-г харьцуулах.
- Шинэ хэрэглэгчийн үүссэн шалтгаан, зөвшөөрлийг шалгах.
- Sysmon Event ID 1 болон Windows Event ID 4688-аас нэмэлт үйл ажиллагаа шалгах.

### Containment
- Хэрэв зөвшөөрөлгүй үйл ажиллагаа батлагдвал эрх бүхий ажилтанд escalation хийх.
- Нотолгоог хадгалж, эрсдэлийн хэмжээнд тохирсон account lockout эсвэл host isolation шийдвэр гаргах.

### Eradication
- Зөвшөөрөлгүй данс, persistence механизм батлагдвал зөвшөөрөлтэйгөөр устгах.
- Нууц үг болон хандалтын тохиргоог шаардлагатай тохиолдолд шинэчлэх.

### Recovery
- Цэвэр системийн төлөв болон логийн бүрэн бүтэн байдлыг шалгах.
- Системийг хэвийн горимд буцааж, давтан халдлагыг хянах.

### Post-Incident
- Инцидентийн тайлан гаргах.
- MFA, account lockout, alert correlation зэрэг хамгаалалтыг сайжруулах.

## 6. Эцсийн дүгнэлт

WIN-EP01 төхөөрөмж дээр олон удаагийн амжилтгүй нэвтрэлт, түүний дараах амжилттай нэвтрэлт, шинэ хэрэглэгч үүсгэлт болон Users бүлэгт нэмсэн үйл явдлууд бүртгэгдсэн.

Эдгээр үйл явдал цаг хугацааны дарааллаар ажиглагдсан ч нэг халдлагын гинжин хэлхээ гэдэг нь батлагдаагүй. Тиймээс инцидентийн шинжилгээг нотолгоонд суурилж, батлагдсан үйл явдал болон таамаглалыг тусад нь баримтжуулав.
