### Системийн асуудал

#### Цагийн мэдээллийн зөрүү

Windows-ийн шалгасан локал цаг UTC−7, dashboard UTC+8 байсан.
Локал цагийг хөрвүүлж харьцуулсан.

services.exe-ийн Sysmon EventRecordID 3616-ын эх XML-д:

- System.TimeCreated.SystemTime: 2026-10-21T01:41:24.8840794Z
- EventData.UtcTime: 2026-10-21 16:41:10.337

Зөрүү эх XML дотор байгаа бөгөөд шалтгааныг тогтоогоогүй.
Энэ нь үйл явдлын дараалал болон процессын холбоог
тогтооход хүндрэл учруулж байна.

#### Эх процессын мэдээлэл дутуу

Issue #4-ийн svchost.exe бүртгэлд ParentImage байхгүй,
ParentProcessGUID бүхэлдээ тэг утгатай.

Rule 61618 нь svchost.exe процесс үүсэхэд таардаг.
Rule 61619 нь parentImage-д services.exe таарвал level 0 болгодог.
ParentImage байхгүй тул энэ бууруулах нөхцөл таараагүй.

#### SSH холболт

Шалгалтын үеэр Connection reset гарсан.
Дараа нь WIN-EP01 дээр дахин шалгаж гарын үсэг, hash-ийг баталгаажуулсан.
Үндсэн компьютер дээр андуурч авсан hash-ийг кейсийн нотолгоонд ашиглаагүй.

Agent-ийн одоогийн Active төлөвийг ээлж хүлээн авахдаа дахин шалгана.
Agent унтарсан гэж баталгаажаагүй.

### Дараагийн ээлжид анхааруулах зүйл

1. Issue #4-ийн 10:36:24.481 цагтай өөр rule 61618 alert-ийг харьцуулах.
2. services.exe-ийн эх XML дэх цагийн зөрүүний шалтгааныг нягтлах.
3. Issue #2-ын DLL үүсгэлтийн шалтгааныг үргэлжлүүлэн шалгах.
4. Issue #3-ын бүтэн хугацааны шалгалтыг дуусгах.
5. Даалгаврын шаардлагатай тав дахь alert-ыг сонгож Issue #5 үүсгэх.
6. Шинэ кейсийг шалгаж эхлэх болон дуусах бодит цагийг шууд тэмдэглэх.
